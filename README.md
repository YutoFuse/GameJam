## 概要

「カックンパックン」は，「Global Game Jam 2026 瀬戸内会場 in 広島」にて，
初対面の5名チームで48時間以内に制作したパズルゲームです。

プレイヤーはカックンを操作し，ステージ内の状況に応じてマスクを装着させながら，
条件を満たすことを目指します。

[unityroomでプレイする](https://unityroom.com/games/kackun_packs)

## 開発情報

- 制作イベント：Global Game Jam 2026 瀬戸内会場 in 広島
- 開発期間：48時間 + 2~3時間（イベント終了後のブラッシュアップ）
- 参加人数：5名

  - エンジニア：2名

- 使用エンジン：Unity 6（6000.3.6f1）

## ゲーム内容

### ジャンル

パズルゲーム

### 操作方法

| 操作 | 方法 |
|---|---|
| カックンの移動 | マウスのドラッグアンドドロップ |
| マスクの装着 | マウスのドラッグアンドドロップ |
| 決定 | ボタンのクリック |

### ルール

- カックンをドラッグアンドドロップで上下左右に移動させます。
- 隣り合うカックン同士の目・口が同じ場合，その方向へ移動できます。
- 移動すると，移動した側のカックンは消え，移動先のカックンの顔が残ります。
- 目・口の両方が一致しない場合でも，目か口のどちらかにマスクを付けることで，一部の条件を無視できます。
- マスクで隠していない部分が一致していれば，カックンを移動させることができます。
- 移動時に使われたマスクは，移動後に削除されます。
- カックンが最後の1匹になるまで移動を繰り返し，ステージクリアを目指します。

## 工夫した点

### プランナー
- プログラマーとデザイナーに仕事が無い時間を無くすために、仕様内容を1日目にほぼ固めて伝達した。
- チーム制作が初めての方が多かったので、伝達手段もホワイトボードなどのみんなが話し合いながら確認できるものを選んだ。

### プログラマー
- できるだけプランナーやメンバーに設計・用途が伝わるよう、インスペクターの表示内容や口頭・Discordでの情報伝達を意識した。
- 短い時間の有効活用のため、コンフリクトが発生しないようにシーンやスクリプトを分けて作業した。
